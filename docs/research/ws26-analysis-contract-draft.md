# WS-26 原始数据与双主结果分析契约草案

状态：草案，等待候选、正确性与独立资源 pilot 后最终冻结。日期：2026-10-07。此文只确定用户已确认的比较口径及分析实现要求；尚无 WS-26 正式 seed、输入哈希、仿真 SHA、实验 ID 或结果。

## 实验单位与主判据

正式主条件唯一为 PFC=1、IRN=1。每个新独立需求 seed 的 0/64/128/192 档六臂共用逐字节相同的档位 trace，主矩阵为 24×4×6=576 格。192 档 MoE 合成批次完成时间定义为该档全部 16,384 条 MoE 流的最后完成绝对时刻减共同 2.000 s 起点。背景 P99 定义为该档全部 192 条 8 MiB 背景流 FCT 的线性插值第 99 百分位。两指标越低越好。

逐 seed 对 ECMP 的变化为 `100 × (候选值 / ECMP 值 − 1)`。两项分别要求 24 个配对变化的中位数 ≤−3%，且至少 17/24 个 seed 严格小于零；等于零不计改善。两项均满足才判主 GO。完整报告每 seed 绝对值、差值、比率、改善方向、区间和反例；任何一项失败仍完成预设正确性、敏感性与逐格验收，再报告有边界的 NO-GO。24 个 seed 是统计单位；流、档位、算法臂和四传输设置均不另计 n。

0 档只检查 MoE；64/128 档同时检查 MoE 与背景 P99。各可定义约束项相对 ECMP 的 24 seed 中位恶化 ≤+5%，且恶化 >+10% 的 seed 至多 4/24。0 档背景 P99 标为不适用。低档约束不是新主结果，也不与 192 档合并选择有利设置。

DRILL、CONGA、LetFlow 和 ConWeave 是四个固定次级对照。192 档每个对照都计算两项配对变化、严格改善数和精确符号检验；联合 p 取两项较大值，再对四个联合 p 用 Holm 法控制族错误率 0.05。仅在主比较通过时，才按既定幅度、方向与 Holm 结果评价次级的共同改善；所有对照的负向及反例仍如实报告。MixHash 仅作设计参考，不进入此比较族。

## 完整性与辅助结果

逐格从 metadata、配置快照、trace、拓扑、FCT raw 与资源收据复核源码 SHA、模式、传输设置、ns-3 seed、输入哈希、原 ID 和运行顺序。全输入 QP 的身份、标签、大小、起点、完成条数、重复行和字节守恒必须匹配；任一输入流未完成，该格的性能值未定义，不能只对已完成流算均值或 P99。候选路由计数、缓存、类别队列和退回路径需与代码语义一致，原始失败 ID 保留。修复后使用新 SHA、新 ID 重验受影响配对。

每格额外报告 PFC pause/resume 原始次数、MoE **单流** FCT 平均值和 P99，作为辅助诊断。PFC=0 的格应核对 PFC 事件语义；PFC=1 的零事件只表示这次输入未触发。背景单流平均/P99、尾流身份、CNP/ECN、乱序/SACK、重传/超时、活跃上联利用率及类别队列作为解释指标；若缺可观测原始链路，就标记缺失。辅助指标不加入新的 GO 门槛。

## 传输敏感性与异常处理

同一 24 个新 seed、四档、候选与 ECMP，在余下 PFC×IRN=（0,0）、（0,1）、（1,0）各运行一格，共 576 个敏感性格。它们与主矩阵合计 1,152 格。每种设置单独报告全部完成率、资源、两类效果和辅助指标；对照主条件时按相同 seed 配对，明确重复测量关系。不得把四设置拼成 96 个独立 seed，也不得根据敏感性结果事后改选主设置。

任何设置的正确性失败，先暂停后续相应格，定位并修复，再评价该设置的效果。不能将未完成流筛掉以获得看似较优的 FCT。SSH、构建、回传或资源异常按原 ID/PID/raw 防重恢复；失败原始数据与修复记录并列。性能方向不触发选择性早停。正式数据全部终态回传并逐格验收后，实际切至 GPT-6 Sol High 执行统计、反例和证据等级分析。
