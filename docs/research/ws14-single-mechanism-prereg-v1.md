# WS-14 单机制研究小样契约 v1

冻结于首次 WS-14 仿真前。状态：**研究性小样，不是业务安全或正式效果验证**。本文件随源码提交固定 SHA；运行收据以该 SHA、实验 ID、trace/拓扑哈希和原始 FCT 为准。

## 可证伪假说与唯一改动

目标现象是 WS-13 在慢背景 QP 上观察到的目的 ToR 出口排队（最大等待 3.14–3.99 µs）与逐 QP CNP；该并存关系尚未证明因果。候选机制是 WS-09 已实现的 `guardhash`（模式 14）：仅 tag=2 的 MoE UDP 数据采用固定双候选，在总出口队列字节之外给当前 tag=1 背景队列字节加权，`lambda=1, tau=0`。tag=1 背景和控制包保持流 ECMP。相对普通 `shortq2`（模式 13），**唯一评分差异**是候选出口上的背景队列字节项；不启用 HarmGate（模式 15），不更改接收、重传、PFC、IRN 或其它路由模式。最小实现改动为沿用已实现模式与默认参数，加独立实验控制器和分析收据，不把原型已存在误称为已有效。

假说：在原始全量同步 MoE 加 192 条背景的极端格，类别队列惩罚会使 `guardhash` 相对 `shortq2` 改变源 ToR 候选选择，减轻至少一条 WS-13 已定位慢背景 QP 的目的 ToR 出口排队/CNP 与 FCT，同时保留相对同档全流 ECMP 的 MoE 批次收益。反证包括评分动态未触发、尾流仅迁移到其它背景 QP、背景代价加剧、或 MoE 未优于 ECMP。即使观察到预期方向，队列和 CNP 仍只是机制链条的相关观测，不自动构成因果分解。

## 输入、对照与观测

- 固定 `topo_1280_400G_400G_OS1`、400 Gbps、9 MiB buffer、DCQCN、PFC=0、IRN=1、ns-3 seed=1、0.01 s 流量时长。保持同一批 16,384 条 8 KiB MoE 流，背景按原始 WS-11 输入嵌套追加 0/64/128/192 条 8 MiB 流；每档总提供字节随之增加。每档五模式逐字节共用 trace：`fecmp`、`dualtrack`（逐包哈希）、`shortq2`、`packet-drill`、`guardhash`。前四者是独立对照；机制增量首先比较 `guardhash−shortq2`，绝对收益另对 ECMP。DRILL 信息预算不同，单列强对照。
- 首轮正确性/极端格为 0 背景的 `shortq2/guardhash`、192 背景的全部五模式，共 7 格。0 背景预期二者 FCT 字节哈希相同（无 tag=1 队列）；不同即停止检查实现。192 背景启用 WS-13 只观测探针，查看旧尾流目的主机 856/576 的逐 QP CNP、SACK 和每跳队列等待。中档 64/128 与 0 背景其余对照只在极端格完整且未触发停止规则后补齐，用于四档离散连续权衡；不在两点之间插值或称独立需求重复。
- 每格从输入 trace 核对 MoE/背景完成数（包括超时截尾流），并记录绝对 MoE 合成批次 µs、热点最后完成时刻、背景逐流 FCT、P95/P99/最大 FCT 与有效吞吐、与同档 ECMP 的逐流配对差及队列/CNP 事件。损害曲线以背景 P99 差 µs 为横轴、ECMP 减候选 MoE 批次 µs 为纵轴，按 0→64→128→192 连线；另列 P95、最大值和背景逐流正负差分布，不以单一 P99 掩盖尾部迁移。
- `WS09_ROUTE` 的 two_candidates/scored/diverted 和逐端口 `WS09_QUEUE` 守恒是模式动态/正确性门槛。`WS13_HOP` 只覆盖指定目的主机的 tag=1 包；`WS13_QP` 用 `irn_nack_size` 区分 IRN ACK/SACK。仍缺 MMU 总 buffer、每包 ECN 标记、即时 RNIC 速率和有效逐 QP timeout；未观测事件不得写成零。

## 事前停止规则与解释边界

任一格源码/输入哈希不一致、流未全完成、PFC 触发、队列守恒失败或资源异常时停止新增格并保留原始数据；不使用仅已完成流的 P99 排名。若 192 档 `guardhash` 相对普通双候选没有评分/选路增量，或相对同档 ECMP 没有 MoE 批次改善，或原目标尾流没有改善且背景尾部迁移/加剧，停止扩展 WS-14；如有混合结果，报告完整权衡但不启动 WS-15。只有两类流完整、目标尾流与 MoE 的双侧方向均清晰，才补中档并讨论独立需求正式验证。这里没有业务 SLO，也不设通用安全百分比；WS-10/11/12 的历史预注册 no-go 不改判。WS-13 三条校准 trace 仅用于背景波动认识，不参与未来 WS-15 确认性重复。
