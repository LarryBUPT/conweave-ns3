# WS-26 MoE 逐跳配对诊断

状态：2026 年 10 月 10 日事前冻结，尚未执行。此诊断只检验已揭盲 pilot 的机制反例，不增加独立需求样本，也不重新判定候选效果。

## 问题与可证伪预测

ClassLane v4 r2 的高档 pilot 中，四个 seed 的 MoE 整批完成时间均比 ECMP 慢。[既有分析](ws26-classlane4-pilot-r2-analysis.md)给出的配对中位变化为 +20.851%。背景 P99 只有 2/4 个 seed 改善。两项均未通过事前筛选，条件低档保持关闭。

[背景逐跳分析](ws26-v4-ecmp-hop-diagnostic-analysis.md)补齐了 192 条背景 QP 的 ECMP 路径和出口等待，但没有 MoE 逐跳记录。已完成的只读 MoE 事实提取显示，v4 的单流平均和 P99 FCT 均变慢。v4 的非零 CNP QP 数较 ECMP 多，但 seed 95 的最晚 v4 QP 没有 CNP。因此，反馈计数尚不能解释整批退化。

本诊断检验一个有限预测：如果可选上游路径上的出口排队是 v4 整批退化的主要机制，那么四个 seed 中，v4 的慢 MoE QP 应在同口径的可选区域显示一致增加的等待，并能与同身份 ECMP QP 的 FCT 变化对应。若慢 QP 没有相应等待、方向跨 seed 不一致，或差异主要位于目的主机唯一出口，这个机制预测不成立。任何正向迹象仍只是第三候选设计的线索，不构成因果证明或收益证据。

## 固定源码、输入与实验单位

诊断源码固定为 `3bdb6c520a079a79f915300c7540fe1828f4445a`。它只在 `WS26_MOE_HOP_DIAG=1` 时为 MoE UDP 数据包记录出口逐跳摘要，输出 `WS26_MOE_HOP`；背景流继续输出 `WS13_HOP`。两类记录都来自设备出口队列。它们不是 MMU 物理占用，也不能把不同包的逐跳峰值相加为 FCT。新开关须与 `WS25_DIAG=1` 一起启用，其他仿真设置保持原样。

主诊断使用已揭盲的 `20262694～20262697` 四个 seed。每个 seed 各有 ECMP 和 v4 一格，独立分析单位为 seed；16,384 条 MoE QP 及 192 条背景 QP 是该 seed 内的观测，不能充作 16,576 次独立重复。拓扑、逐 seed trace 哈希、原配对 ID 和十个新 ID 见[冻结机器计划](evidence/ws26-moe-hop-diagnostic-plan.json)。计划 SHA-256 为 `ea17bce8eda8441d16139acafd9849bc3c3de615be6b9b797f4e46f65db7f5ea`。拓扑 SHA-256 为 `74a6f7154ca10c3cd6dfd45046c4f8abf0ce27faa8ad11446b6a52920b83afba`。

先做 mixed8 的 ECMP 与 v4 两格正确性检查。主诊断八格使用 192 条背景流，PFC=1、IRN=1、DCQCN、ns-3 seed 1、400 Gbit/s、9 MiB buffer、`netload=10` 和 `simul_time=0.01`。实验顺序固定为 mixed8 两格，然后按 seed 升序交替执行 ECMP 与 v4。每个新 ID 都有独立源码、配置、日志和 raw 目录；原 pilot 与旧诊断 ID 保持原状。

## 执行门与逐格验收

唯一实验副对话负责远端执行和原始数据验收。启动前先确认唯一 runner、其他用户作业、系统健康和十个新 ID 无冲突。每格 build 与 run 前重新过资源门，run 前确认 watcher 首次采样。首个高档 ECMP 格也是资源 pilot；通过资源收据和原始验收后，才能继续其余七格。全程 cap=1 串行。进程树 RSS 峰值上限为 32,768 MiB，可用内存下限为 32 GiB，剩余磁盘下限为 100 GiB，一分钟负载上限为 20。出现争用或资源异常时暂停新格。

每格核对固定源码 SHA、环境开关、拓扑和 trace 哈希、配置、运行参数、成功终态及资源收据。mixed8 必须完成 8/8 条输入流，高档必须完成 16,576/16,576 条。每条输入流的身份、类别、大小和起始时刻应与原 trace 一致，且恰好完成一次。新格原始 FCT 的 SHA-256 必须与计划所列普通配对格一致。mixed8 的 4 条 MoE 与 4 条背景 QP、高档的 16,384 条 MoE 与 192 条背景 QP，都须各有完整逐跳记录。逐 QP 路径需能按拓扑连通，相同 QP 的数据路径应稳定；`WS13_INFLIGHT unpaired=0`。若 mixed8 未通过，这批高档格不得启动。

任一格的输入、FCT parity、路径覆盖、队列守恒或资源门失败，立即停止后续格，保留该格 raw。先定位失败；需要修复源码时，使用新固定 SHA 和新 ID，不能覆盖既有结果。高档格的巨量逐跳日志可能改变内存、磁盘和运行时间，首格资源 pilot 必须实测这些开销。

## 配对分析与结论边界

十格全部通过后，按相同 seed、相同 QP 身份配对 ECMP 和 v4。先报告每个 seed 的 MoE 单流 FCT 分布、最晚 QP、整批完成时间、背景 P99 和 PFC 次数，再按源 ToR、可选中转区域和目的 ToR 列出逐 QP 出口等待及队列字节分布。对慢 QP 列出实际路径、每跳端口、FCT、CNP 计数和逐跳最大值；逐 seed 检查预测及反例。路径改变的 QP 先按区域比较，不把不同端口的数值写成同一端口的配对变化。

输出应保留每格原始文件哈希、输入和资源收据、逐格验收结果、分析器版本及机器可读摘要。分析只决定第三候选是否具有独立、可证伪的机制理由。四个 seed 已揭盲，慢流也属于事后选择；不以本诊断重新筛选 v4、不启动 v4 的条件低档，也不把诊断结果计入正式收益矩阵。

WS-26 仍为 ACTIVE。正式新 24 seed 的 PFC=1/IRN=1 六臂 576 格主矩阵，以及其余三种传输组合的 ECMP/候选共 576 格敏感性矩阵，仍待候选通过准入后执行。正式主门槛保持为：192 档 MoE 整批与背景 P99 各自的配对中位变化 ≤−3%，且各至少 17/24 个 seed 严格改善；低档约束、Holm 校正、MoE 单流平均/P99 与 PFC 次数继续保留。
