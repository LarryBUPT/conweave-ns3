# WS-15 独立需求正式验证门槛复核

日期：2026-09-28。结论：**门槛 no-go；本工作流不启动确认性矩阵。**这是前瞻性问题筛选和既有原始证据复核，不是一次新的效果实验，也不是“所有可能机制无效”的结论。WS-10/11/12 的各自预注册 no-go 原样保留。

| DRILL 或逐包策略再跑独立需求 | 需求重抽后，信息更丰富的 DRILL 是否有连续双侧权衡 | 三条校准输入同配对双侧方向有利，但 WS-12 旧输入的 DRILL 在 20261103/128 背景越线；DRILL 使用缓存目的端最优口和随机候选，与 GuardHash 的信息预算不同 | 是有价值的**异质性问题**，不是新单机制；校准点太少，不支持宣称新效果或事后重判旧判据。可在 WS-16 作为条件性观察与复现问题陈述 |

没有一个**新**候选同时具备独立机制理由、针对性可观测链条、等信息强对照和事前双侧小样设计。故不创建新的算法实验分支或正式输入，亦不占用远程仿真资源。这个决定不把“没跑”记为候选性能失败。

## 未来重开时必须先冻结的契约

若后续获得不同于本次筛选的具体机制与可观测信号，先另立分支，在任何候选性能格之前写明唯一代码改动、激活计数、失败反证与观测覆盖。技术小样需按同字节 trace、同拓扑、seed、DCQCN/PFC=0/IRN=1 比较全流 ECMP、等信息预算消融和独立强对照 DRILL；先核对两类输入流全部完成、PFC/队列守恒/原始 FCT 与资源收据，再看 0 和 192 两端的 MoE 批次、背景 P95/P99/最大及逐流正负差。候选至少须在 192 档相对 ECMP 显示 MoE 批次改善，同时没有靠把背景损害迁给别的 QP 获取表观 P99 优势；混合方向只报告权衡，不打开正式矩阵。小样的数值不进入确认性估计。

只有双侧小样清晰后，正式运行前才冻结独立重抽需求 trace 的生成种子与文件 SHA、每组固定 MoE 加嵌套 0/64/128/192 背景、总提供字节、同组同档配对模式与运行顺序。每条**独立需求 trace**是推断重复单位，不能把流、同输入重跑、旧顺序置换、WS-13 三条校准 trace 或 WS-14 单输入当成独立样本。首要报告量为同档候选−ECMP 的 MoE 批次 µs 与背景 P99 µs，另报 P95、最大、逐流尾部、有效吞吐、完成率、CNP/队列/重排及状态成本；DRILL 分层列出，不当作等信息消融。预先确定需求 trace 数、主档、效应量估计和不确定性方法、缺失/失败格处理、逐档完整权衡与停止规则。没有可核验业务 SLO 时不设通用安全百分比；只给连续 MoE—背景损益和敏感性分析，研究性门槛须清楚标注。冻结之前绝不启动确认性矩阵。
