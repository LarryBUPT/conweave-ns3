日期：2026-09-28。状态：**极端格技术/研究 pilot 完成；按事前规则停止，不进入中档或 WS-15。**没有业务安全线，也不声称因果或普遍效果。

## 冻结设计与证据归属

预注册见 [WS-14 契约 v1](ws14-single-mechanism-prereg-v1.md)，机器重算见[逐格分析 JSON](evidence/ws14-small-analysis.json)，重算入口为 [`run_ws14_small.py`](../../scripts/run_ws14_small.py) 和 [`analyze_ws14_small.py`](../../scripts/analyze_ws14_small.py)。固定仿真源码 SHA `73401ce3ac0a5c27bf0e3e0636c9337056d9355e`，个人 fork 分支 `feature/ws14-single-mechanism`。同一 1280 主机 400G 拓扑（SHA-256 `74a6f7154ca10c3cd6dfd45046c4f8abf0ce27faa8ad11446b6a52920b83afba`）、DCQCN、PFC=0、IRN=1、seed=1、9 MiB buffer；192 档固定 trace SHA-256 `bf1a1960651b2d5bd27cd1304433d489363727a7c02d08c5c05df2b2415d9c8a`，0 档 SHA `9e00baa5c79ab45b107b82b4c18d43cbb9a1073101bf14123aedd2d90d2e89fd`。192 档含 16,384 条 8 KiB MoE 和 192 条 8 MiB 背景流。

单机制候选为既有 GuardHash 模式 14 的背景队列字节惩罚（`lambda=1,tau=0`），与普通双候选 `shortq2` 模式 13 使用相同候选生成规则。比较另含全流 ECMP、逐包哈希、DRILL。没有改接收、重传、传输或 PFC/IRN 设置。本次运行 SHA 与计划保持一致，所有输入按同 trace 哈希核验。

## 原始格与观测

七格实验 ID 均以 `20260927-233000-ws14-` 开头。0 档只跑 `0-q`/`0-g`；192 档依次覆盖 `192-f`/`192-h`/`192-q`/`192-d`/`192-g`，分别是 ECMP、逐包哈希、普通双候选、DRILL、GuardHash。7/7 元数据状态为 `SUCCEEDED`，输入对应的流全部完成。逐格探针验证通过：队列逐字节守恒、0 队列违规、WS-13 未配对包为 0，目标 QP 反馈含明确 `irn_nack_size`；192 档 PFC 文件为空。

0 背景 `shortq2` 与 `guardhash` 的 FCT SHA 完全相同（`ebebc9c3687932ee8b6a854b5d2ba4c7100c3118af0a9a4b3a46847bcd2b8600`），两者 MoE 批次均为 15.637 µs；这符合没有 tag=1 队列字节时评分差异不起作用的预期。

192 档 `shortq2` 与 GuardHash 都完成全部流，且双候选/评分计数均非零。GuardHash 的背景 P99 比普通双候选低 121.477 µs，但其 MoE 批次慢 0.552 µs；相对 ECMP，GuardHash 的 MoE 批次慢 0.731 µs。故未满足冻结的双侧门槛。背景 P99 相对 ECMP仍高 19.360 µs。GuardHash 的背景最大 FCT 1640.274 µs，也没有优于普通双候选的 1650.169 µs 足够形成双侧结论。

WS-13 探针显示 ECMP 最慢的两条背景流 `308→576`、`748→576` 的 FCT 为 1443.874/1420.118 µs，GuardHash 同两流为 1035.831/1391.383 µs；对应 QP CNP 计数从 56/82 变为 45/66。目的出口最大等待则分别从 3617/3625 ns 变成 3664/5240 ns，未一致下降。尾部转移：GuardHash 最慢流变为 `656→856`（1640.274 µs，71 个 CNP，最大观察等待 3950 ns）及 `356→856`（1489.813 µs，68 个 CNP，3945 ns）。这支持尾部流身份与代价可能转移的观察；CNP 和队列等待仍只是同一输入下的相关量，探针不覆盖物理 MMU 总占用、逐包 ECN 和即时 RNIC 速率。

资源监督期间 7 格资源收据完整，最低可用内存 114.16 GiB，最低磁盘余量 5777.26 GiB，资源 watcher 报告进程树峰值 RSS 约 4540.59 MiB；结束后无在途仿真，服务器 1 分钟负载为 0.0。

## 停止决定与范围

冻结规则要求候选相对同档 ECMP 有 MoE 批次改善，同时目标尾流改善且不发生背景尾部转移/加剧。GuardHash 相对 ECMP 没有 MoE 改善，最慢背景 QP 转移，目的出口最大等待也没有对旧尾流一致改善。因此在极端格停止，不运行 64/128 档；本次没有形成 0/64/128/192 连续曲线。报告保留 0 与 192 两个观测端点，不插值，也不把这个 single-seed、小输入 pilot 称为安全结论。WS-15 不启动。WS-10/11/12 各自既有 no-go 完全不变；WS-13 三条校准 trace 不用于本次实验或 WS-15 确认性重复。
