## 候选论文复核

复核入口为项目的候选索引和累计阅读记录，并对照对应固定版本分析与核验文件。Gemma 使用 HPCC 2024 正式论文版（DOI：`10.1109/HPCC64274.2024.00151`）。它把远端出口队列、接收侧重排、队列用量和 FCT 放在一起评估，可借鉴其同时报告队列与尾部指标的观测方法。Gemma 采用逐包改路和接收交换机重排；WS-30 检验的是不同候选端口规则在并发运行时的结果一致性。论文没有研究并行运行不变性，也未提供可独立复算的 seed、原始 trace 和统计区间，因此不能支持本项目的性能主张。

SeqBalance 使用 arXiv:2407.09808v1（2024）阅读版。它可提醒我们先界定包序、QP 和父请求完成聚合单位，再记录反馈与恢复成本。其方法把一个请求拆分到多个 QP，并让每个子流固定走一条路径；WS-30 保留候选对并逐包重算端口，机制不同。该论文没有说明足以独立复现的 seed 与重复次数，也没有研究并行运行不变性或本项目的双侧主指标。其正式期刊版已登记，但未完成最终正文逐项比对。本节点只借鉴评估问题，不将论文报告的效果外推为本项目收益。
