## 路径与传输核验

独立脚本检查了 22 格完整逐包日志，共 128,023 个包、640,115 次交换机转发记录和 2,220 个 QP。脚本依据实际拓扑重建源端到目的端的每跳路径，检查路径连续性、候选端口和记录队列值是否符合对应算法的决策规则。固定路径臂没有出现路径变化；U16 主技术格中有 109 个 QP 实际使用多条端到端路径。

观测日志覆盖单出口、哈希碰撞、空队列平局、非空平局和严格总队列排序。跨 22 格共记录 8 次“总队列相同、背景队列组成不同”的决策情况，其中 7 次加入背景队列后改变候选选择。E 与 H12 的实际路径签名一致。协议计数满足 `fd_feedback_frames = fd_without_sack + sack_feedback`；重传包数与重传字节数同时为零或同时非零。计数边界仍按冻结计划解释：普通 IRN ACK 也可能是 `0xFD` 帧，不能将它单独认作丢包 NACK。
