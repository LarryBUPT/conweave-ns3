# WS-26 ClassLane v4 独立需求 pilot 协议

状态：r2 高档与条件低档计划已冻结，尚未启动。日期：2026-10-09。本协议只用于候选筛选，不作为正式效果证据，也不改变 WS-25 的 NO-GO 结论。

v1 计划曾加入 ClassReserve v3 专用的 `with_background` 覆盖门。ClassLane v4 没有该计数器，候选规格也未把机制覆盖设为额外筛选门。v1 的计划与 ID 保留作审计记录，全部未运行；本协议与 r2 计划取代它。

## 固定源码与输入

仿真固定使用源码 SHA `41384701c865082655cdea9a9e64daae74f51327`。拓扑为 `topo_1280_400G_400G_OS1`，SHA-256 为 `74a6f7154ca10c3cd6dfd45046c4f8abf0ce27faa8ad11446b6a52920b83afba`。

四个独立需求 seed 为 `20262694～20262697`。它们与预留的 24 个正式 seed `20262601～20262624` 分离。每个 seed 有 0、64、128、192 条背景流四档 trace。高档 pilot 只运行 192 档。全部 16 份 trace 的 SHA-256、预期流数、52 个 r2 实验 ID 和顺序见[r2 冻结计划](evidence/ws26-classlane4-pilot-plan-r2.json)。v1 ID 不得复用。

trace 由 `scripts/make_ws26_demand.py` 按已核验的 WS-25 抽样规则生成。新增 trace 与仿真固定 SHA 分开提交。因此，每个远程 ID 完成 build 后、run 前，runner 必须把该格 trace 复制到隔离源码目录的 `source/config/`，再核对其 SHA-256。

所有格使用 400 Gbit/s、9 MiB buffer、DCQCN、PFC=1、IRN=1、ns-3 seed 1、`netload=10` 和 `simul_time=0.01`。每个 seed 的配对算法臂共用同一份逐字节输入。

## 高档筛选

第一阶段共 28 格。每个 seed 运行 ECMP、DRILL、CONGA、LetFlow、ConWeave、ClassLane v4 六臂，并运行一格带诊断开关的 ClassLane v4。固定随机种子 `2026100901` 生成臂与 seed 的顺序。诊断格紧跟同 seed 的候选格。

每个 seed 分别计算 MoE 整批完成时间和背景 FCT P99 相对 ECMP 的配对变化：`100 ×（ClassLane v4 / ECMP − 1）`。MoE 整批时间是全部 MoE 流最晚完成绝对时刻减 2.000 s。背景 P99 使用 192 条背景流的线性插值第 99 百分位。

两项指标都必须满足以下条件，才通过高档效果门：

- 四个 seed 的配对变化中位数均不高于 −3%。
- 每项指标至少有 3 个 seed 严格改善；变化为 0 不计作改善。

两项效果是唯一的高档筛选门。机制观测不增加 seed 通过门槛。每个候选格报告两类包数、QP 新建与复用数、改选数、ECMP 回退数、端口包数和队列守恒。每个 seed 的诊断格记录逐 QP 路径及交换机—目的 ToR 的类别端口集合，并须与普通候选格的 FCT 原始文件 SHA-256 相同。

四 seed 的筛选门只决定是否投入下一阶段，不估计总体收益。所有反例都保留，不通过改门槛或调参消除。

## 条件低档检查

高档双指标效果门通过后，才运行 24 格条件低档检查。每个 seed 在 0、64、128 档各运行 ECMP 和 ClassLane v4。0 档背景 P99 记为不适用。

低档每项适用指标相对 ECMP 的四 seed 配对中位恶化不得超过 +5%。恶化超过 +10% 的 seed 不得多于 1 个。低档越线时，不冻结当前版本进入正式矩阵；已运行结果和 raw 仍保留。

## 逐格验收与资源线

build 前核对固定源码、拓扑、输入哈希、实验 ID 与远端现有目录。任何 ID 已有结果时，按原收据处理，不覆盖 raw。候选格还须核对参数、配置快照、完整流身份、标签、大小、起始时刻和 tag。每条输入 QP 必须恰好完成一次；缺失或重复时，该格性能值无效。

ClassLane 格还须核对逐 QP 选路稳定、逐标签包数、新建与复用计数、改选计数、回退计数及队列字节守恒。诊断开关格的 FCT 原始文件哈希必须与同 seed 普通候选格相同。每格均须取得终态资源收据和至少一条 watcher 采样。

调度上限固定为 cap=1。进程树 RSS 峰值不得超过 32,768 MiB；可用内存不得低于 32 GiB；剩余磁盘不得低于 100 GiB；采样的一分钟负载不得超过 20。开始前确认无人作业、无活跃仿真和无持有中的实验锁。每格 run 前先启动 watcher 并确认首条采样。

## 停止与恢复

正确性、身份、输入哈希、诊断非扰动或资源收据任一失败，都暂停新格并定位原因。失败 ID、日志和 raw 保持原状。修复后使用新源码 SHA 与全新 ID，重验受影响的配对。恢复时只按已核验收据跳过终态格，不覆盖已有数据。

所有 28 个高档格终态并逐格核验后，才计算双侧门槛。高档效果门未通过时，24 个条件低档 ID 保持未启动。pilot 完成和结果分析仍不能替代 WS-26 的 576 格正式主矩阵、576 格敏感性矩阵及最终闭环。
