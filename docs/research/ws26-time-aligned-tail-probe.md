# WS-26 已揭盲尾流时间对齐探针

状态：代码待远端编译与非扰动验收。此探针只用于解释已揭盲的 WS-25 反例，不计入 WS-26 独立 pilot 或正式矩阵。四格统一使用 PFC=0、IRN=1、400 Gbps、9 MiB buffer、OS1 拓扑、固定 0.01 s 仿真时长。源码 SHA 在首次远端 build 前登记，四格相同；不得复用旧 ID 或覆盖旧 raw。

## 选择规则与观测

按[两格配对复算](evidence/ws26-ecmp-paired-tail-diagnostic.json)中 ClassReserve 相对 ECMP 退化最大的背景 QP，各事后选 5 条。64 档为 `692→1052:10001/102`、`1076→1040:10002/103`、`408→1040:10000/101`、`1016→1052:10000/101`、`1016→1040:10002/100`；192 档为 `28→1176:10004/101`、`164→1176:10002/104`、`56→64:10000/100`、`976→324:10000/100`、`292→1116:10001/102`。冒号后是源端口／目的端口。选择集合固定在 [`ws26-time-probe.h`](../../src/point-to-point/model/ws26-time-probe.h)，探针不按新结果重选流。

`--ws25-diag 1 --ws26-time-probe 1` 同时开启已有逐 QP／逐跳汇总和新增时间探针。新增 `WS26_QP_EVENT` 记录选中 QP 收到 CNP 与发送速率变化的 `time_ns`、身份、确认序号和当前速率。`WS26_ECN_BUCKET` 将选中流在交换机出队时作出的 ECN 标记决定按 10 µs、交换机、端口和流聚合；`WS26_ECN_SUMMARY` 给出桶数和溢出。每条 QP 最多输出 4,096 个事件行，全局最多 8,192 个 ECN 桶；任一截断或溢出都使时序解释不完整。该记录只读，不进入选路、拥塞判断或发包逻辑。时间对齐可检验标记决定、CNP 到达和速率调整的先后，仍不能单凭观测证明因果。

## 逐格验收与判断

远端由唯一实验副对话串行执行，cap=1；先按原 ID 查询 metadata、PID 和 raw，再决定是否 build／run／fetch。每格验证固定源码、拓扑与 trace 哈希、对应 16,448 或 16,576 条输入 QP 的完整身份和完成、FCT 与上表原正式格**逐字节**一致、逐跳未配对数为 0、资源采样与终态齐全、10 µs 桶及 QP 事件可解析且无截断。新探针 FCT 指纹若不同，暂停后续格，定位并以新 SHA／新 ID 修复复验；不得把非扰动失败的诊断当作机制证据。

只有四格全部通过，才按同流同时间轴比较上游与目的出口的标记决定、反馈到达和速率轨迹。64 档 `1568:1` 汇聚、192 档目的主机 1176 的两条最重退化流都必须单列；同时报告与假说相反的流。无论结果是否支持本地背景占用方向，都须在独立需求 pilot 前只冻结一个主候选和替代解释，不按这些已揭盲流调正式效果阈值。
