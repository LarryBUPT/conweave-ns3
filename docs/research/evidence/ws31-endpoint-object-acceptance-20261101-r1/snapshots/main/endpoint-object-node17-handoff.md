## 4. 已形成的设计决策

八组真实对象的手工状态双读验证：完整协议字符串在进程内相同，显示用 FNV 不是唯一依据。IRN 两块 SACK 原值、保守 pending、实际完成与旧 finished 位的区别、保留旧槽并追加新 QP、完成历史、live RX、物理与 ACK 队列、事件与发送占用均有 raw。十四项 Read 拒绝前后也核协议字符串。

mask 保持 127，未置交换机覆盖位；完整 ALL 值为 255。没有调用 Simulator::Run，四个未来 Noop 未执行，实际网络完成为 0。手工追加槽位与自然第二代网络发送分别验收。后继 channel token 必须在整个 Receive 返回之后闭合，不能用映射已删除或 EventId expired 替代。
