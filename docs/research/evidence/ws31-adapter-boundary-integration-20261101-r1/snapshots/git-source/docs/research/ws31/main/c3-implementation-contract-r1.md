# C3 新 QP 配额与借用实现契约

日期：2026 年 11 月 1 日。判断：实现为可证伪的准入机制；首先检验非迁移残留，不能把逻辑活动切换当成物理容量回收。

## 1. 规则与控制

源 ToR 按最近 20,000 ns 内观察到的 UDP 数据识别类别活动，不读取完成信号或未来输入。类别在 QP 首次分配时确定，后续包沿该身份更新活动；未知类别使用统一规则。活动窗口是本版本工程初值，不是已验证最优值。

将可用出口按端口号排序，前 `ceil(N/4)` 个归 tag 2，其余归 tag 1。仅有一个出口时不分割。对方类别活跃时，新 QP 只能在本类别集合中选路；对方不活跃时，新 QP 可以使用全部出口。双哈希、严格小于比较和平局保留第一的规则沿 QueuePin；允许两个候选相同。原 next-hop 顺序用于哈希索引，排序只确定出口归属。

模式 47（`ws31-c3`）使用类别与空闲借用；48（`ws31-c3-fixed`）始终按同一配额划分，不借用；49（`ws31-c3-size`）用 8,192 B／8,388,608 B 重建类别，采用同样借用规则；50（`ws31-c3-zero`）直接走 QueuePin。其他跳沿 QueuePin，不叠加 C1 或 C2。

C3 的集合限制会改变候选集合。这是机制动作本身，不能将其与 QueuePin 的差异称为纯类别信息效应。模式 47 与 48 隔离借用规则，47 与 49 检验当前固定两尺寸输入的信息来源；未知标签／零控制用于检查退化行为。没有通过动态验证前，不称本实现优于旧 ClassLane。

## 2. 路径保持与残留

每个四元组首次选择后保持出口。活动到期只改变以后新 QP 的准入资格，不删除路径、不迁移现有 QP。显式 tuple 重建测试的清理钩子同步清除该键的准入状态；普通空闲不自动重建。

借用在首次选择时确定：若已知类别选择另一类别所属出口，记为借用 QP。活动窗口内仍发包的借用 QP 计为近期观察到的借用者。类别由空闲变活跃时记录此类借用者数；借用 QP 在出口所有者活跃后继续到达的包，记入残留包数和线速字节数，包括重传。

这些计数是本地近期活动与持续冲突的观测，不是正在传输的精确 QP 数，也不是可回收带宽。静默 QP 到期后仍保持路径；其迟到包可能再次构成残留。逻辑配额无法收回已经固定在路径上的长 QP，是本版本要验证的主要反例。

## 3. 状态与验收

路径表保留已见 QP，与 QueuePin 具有相同持久路径生命周期；另为近期活跃条目维护一个到期索引，以及两类活动和借用者计数。每包只更新本键和已到期条目；守恒扫描仅在汇总或核心测试执行，不进入常规逐包决策。

核心测试覆盖首次借用、类别重新激活、后续新准入受限、已有 QP 不迁移、精确空闲边界、迟到包、tuple 清理、固定控制、大小控制、未知标签与单出口。后续必须通过完整 ns-3 构建、QueuePin 退化回归、标签干预、动态活动切换及残留非零覆盖。构建和单元测试不能替代端到端及双侧效果验证。
