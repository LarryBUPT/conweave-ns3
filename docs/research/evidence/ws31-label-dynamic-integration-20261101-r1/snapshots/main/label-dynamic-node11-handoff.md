## 4. 已形成的设计决策

原独立检查器错误要求 C3 p1 与 Q12 的全部通用 CHOICE 数及 combined hash 相同。实际 C3 记录 30 条通用 CHOICE 和 15 条专属首次准入，Q12 记录 45 条通用 CHOICE。原冻结判据是完整 FCT、有序 ROUTE 和源首次投影，不要求这两种日志模式相同。

新检查器只修复该模式比较，保留 C2 完整 CHOICE 比较，并拒绝三种离线损坏反例。主重放器在事件前已准备，相关条件及文件哈希未放宽。旧 checker、停止 index、QA、日志和 raw 均保留；旧 C3 p1 的 `raw_preserved=false` 属停止流程的状态标记，实际完整 raw 已在主侧验过，不回写历史字段。

恢复只在新门通过后运行原先 BUILT 且未启动的 c3-p2 和 c3-p3，各一次；新构建、核心、同步、部署及原八格仿真重复均为 0。新结果写入 recovery 自有路径。未建立科学源码失败，也未改变候选阈值。
