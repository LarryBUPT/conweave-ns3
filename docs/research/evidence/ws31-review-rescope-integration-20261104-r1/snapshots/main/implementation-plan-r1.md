## 3. C1 初始工程契约

主模式 `ws31-c1`，独立编号 36。仅源 ToR 改首次选路，其他跳沿 QueuePin；所有 UDP 数据共用同一 12 B 键和双哈希候选。候选重合时退化，平局保留第一候选，后续包保持缓存出口。

初始模板为消息 8,192 B、背景 65,536 B、未知／统一 8,192 B；从首包起固定 20,000 ns 到期。它们是冻结源码中的工程初值，不是已校准或最优参数。背景模板有意限制在 64 KiB，而非把整个 8 MiB 当作真实队列。正式参数需要独立校准协议，不从效果数据搜索。

预算先按名义 MTU 和共同报文开销转换为估计排队字节。后续包按序号区间的唯一载荷扣减，重复和重叠不重复扣减；空洞保持未观察身份。最多 65,536 个预测条目，每条最多 32 个区间；超限仅撤销预测，已有出口保持。到期不删除路径缓存，不凭空闲重建 QP。

观察发生于本交换机准入判断之前；即使随后丢弃，也不再把该次到达当成未见字节。重传不自动创建新预算，可靠性由原传输负责。精确大小统计标签只在命名的大小克隆控制使用；主模式不读取它或未来输入。
