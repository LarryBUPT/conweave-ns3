## 3. 评审中的推断不能直接变成否决门

1. **MAE 更差不等于进度机制已被反证。** 两候选误差可相互抵消，决策依赖两侧差值和 Q。76/83 对 74/83 是描述性差异，不能既当显著正收益，也不能凭 MAE 给它一个未经定义的抵消权重。A 从“未支持”滑到“已反证”（233、307、655 行），措辞过强。
2. **3.3 MB／100 Gbit/s 是聚合链路工作量，不是实际回收时长。** A 168–172、340–355 行把 3,301,200 B 折为约 264.1 μs，再与另一实验的批次比较。算术正确；若字节分布在多端口、多个时间段或多次活跃事件，这个量不提供每次回收的下界，更不能证明借用永远无用。只能据此优先测持续时间。
3. **8 KiB 是请求大小，不能默认是一包。** A 325 行和 B 114 行将其与 500 ns 作包级比较；文内又采用约 1,000 B 载荷 MTU。约 1,048 B 线速包在 100 Gbit/s 下约 83.8 ns，500 ns 可跨约 6 个包时隙。不能完全错开整条请求，不等于无法改变首包选择和后续拥塞。
4. **启发式 oracle 不是最优上界。** A 720–727 行的两三轮坐标下降、分组穷举或近似 ILP，至多找到某个可行分配。对最小完成时间问题，可行解给最优改善的下界；它失败不能证明所有在线策略失败。B 225 行用旧路径 true1／true2 选路再跑一次，也只是一个使用未来信息的启发式臂。未来信息不保证目标最优。
5. **旧日志不能覆盖改变路径后的闭环网络。** 新选择会改变到达、排队、DCQCN／IRN、重传和后续决定；旧路径上的未来量是原策略下的结果。固定路径 oracle 还没有涵盖 C2 的启动时间动作，不能一票停止三项。按跳实际等待也不能在缺入队／出队事件时仅由 ROUTE 行数推得。
6. **机会阈值不是性能定理。** 1%、2%、5%、10%、95% 等均为评审建议，未冻结、未证明。很少几个改变也可能决定批尾；高动作差异、低相关或大小克隆不一致也不等于信息有用。完全无差异可在完整、精确且因果一致的同输入重放中形成局部结论，不能推广到所有需求。

定位：A 275–284、716–760、1138–1170、1708–1734 行；B 221–231 行。A 同时提出“P1–P4 全过才跑效果”（822 行）和 C2／C3 可判负退出，随后又说任意 1–2 个条件成立即可升级（1940–1949 行）；主对话须重写为每个存活候选自己的门，避免无关候选失败阻断其他候选。

## 4. CLC／CDLC／MACA 到底在做什么

| 机制 | 规则与类别角色 | 更新、清理与状态成本 |
| --- | --- | --- |
| CLC（A §4.1） | 短流先比本类最近到达 B₂，再比 Q、U；长流先比最近出队率 U，再比 Q、B₁。类别改变比较顺序。 | 准入后向本类 B 加字节，出队后更新 U，均按时间衰减；没有随出队从 B 扣减，也不随单个 QP 完成清空。是历史活动量，不是未服务字节。端口聚合外加原路由缓存。 |
| CDLC（A §4.2） | 在 CLC 思路上把历史按“端口、目的 ToR、类别”拆开；短流 `(D₂,Q,U)`，长流 `(U,D₁,Q)`。 | 同样按准入累计与时间衰减。只见本源贡献，不见其他源和目的真实排队。8×8×2＝128 个 D；若每类独立时间戳，再加 128 个时间戳和 16 个 U 字段，共至少 272 个新标量，未计容器、映射和现有 Q。 |
| MACA（A §4.4） | 队列差大于 θ 时沿 QueuePin；差值在 θ 内时，短流比 B₂／U，长流比 U／B₁。类别只在近似平局区介入。 | 仍需每包准入／出队更新 B、U。θ 约一包、两个窗口均为 20 μs，只是待冻结初值。它限制介入时的瞬时队列差，没有限制固定整条 QP 后的完成时间代价。 |

三者都未实现、未编译、无效果数据。所谓“短流用短时信号、长流用长时信号”需要解释：类别并不自动代表完成目标、同步性或拥塞时间尺度。CLC／MACA 实际给 B 和 U 相同 20 μs 窗口，也没有论证为何短流只避本类、长流看已完成服务，而忽略跨类竞争。

## 5. 三个提案先要解决的规则问题

| 问题与定位 | 可直接复核的原因／最低成本反例 |
| --- | --- |
| 类间时间戳串扰：A 1052–1053、1317–1318、1618–1619 | 只衰减当前类别，却覆盖共用 `last_B[p]`／`last_D[p,d]`。设 τ＝20，类 1 在 t＝0 留 100，类 2 在 t＝10 到达；t＝20 读类 1 会残留 50，独立按龄衰减应为 0。应每类保存时间戳，或统一先衰减全部类别再推进时间。 |
| 衰减定义与惰性读取：A 1057–1061、1592–1629 | 递归线性因子不是严格滑动窗，也不是精确指数 EWMA，事件分段会改变剩余值。MACA 首包直接读 B／U，没有像 CLC 显式按当前时间惰性衰减。需先定义核函数及读写顺序；空闲超过 τ 的非零旧计数即可暴露陈旧读取。 |
| 无限优先级并非队列回退：A 1037–1040、1303–1306 | 字典序第一键只差 1，也可压过很大的 Q 差。例如短流候选一 B＝1、Q＝100,000；候选二 B＝2、Q＝0，会选一。必须评价这种优先级假设，不能称作队列仍主导。有限离散状态上的字典序也可用充分大的权重编码，“不是加权和”不自动构成新颖性证明。 |
| MACA 零状态退化矛盾：A 1589–1609 对照 1741 | 令 q₁＝1,000、q₂＝0、θ≥1,000，B／U 全零；伪代码保 p₁，QueuePin 选 p₂。若想零状态回归，应在辅助键相等或无效时比较真实 Q。此修改属于提案澄清，尚未获采纳。 |
| 缺状态有三种说法：A 1013、1070、1088、1566、1639、1659 | “缺失即 QueuePin”“缺失按 0”“异常即回退”不等价。未初始化、真实零、过期、缺观测和溢出须分开定义。已识别错误标签也不同于在线未知的合法错标签。 |
| CDLC 并非只加目的维度：A 1040 对照 1306、1368 | CLC 长流为 `(U,Q,B₁)`，CDLC 长流为 `(U,D₁,Q)`；同时交换了 Q 的优先级。不能将二者差异全归为目的信息。其成本表 1354–1358 行也把 128 个时间戳漏成了 16。 |
| CDLC 的目的瓶颈因果缺口：A 1247、1388–1389、1427 | 把本源送往某目的的流换一条脊路，并不减少该目的唯一末跳必须服务的总字节。要区分可绕行的中间竞争、不同主机的下行和同一目的最终瓶颈；本地 D 也看不到其他源。 |
| 类别无关控制仍用类别：A 1118–1123、1377–1382 | 统一 B／D 后仍按类别选择键序，不是真正类别关闭。CDLC 的“端口、无类别”格也不能直接命名为 QueuePin＋U，历史量仍可能存在。应逐臂列出全部读数、键序和更新。 |
| MACA 的 2×2 退化为重复臂：A 1679、1688–1693 | 表中 gate off 两格都是 QueuePin，无法检验“只在近 tie 使用”相对“全局使用”的门控效应。可作嵌套启用对照，不能同时解释成完整因子设计。 |

U 是本地已出队字节率，不是全网拥塞；忙可能表示服务有效，空闲也不代表下游无竞争。按类近期字节同样不等于未来到达或尚未完成承诺。需要测的是它们在可改变的决策面上是否补充信息，而非给状态换个“压力”名称。

C 746 行将 Q 与 R 称为“不同量纲”也不准确：两者都是字节，问题在观测点、时间范围及是否重叠。CCL 同样要解释 Q 与所选域 U 如何排除重复，而不能仅凭账本名称宣称“同时域”。

## 7. 最便宜、且不会误杀方向的检查顺序

以下均为提交主对话的建议，本轮没有执行，也没有批准任何提案或改变工作范围。

1. **先作纸面规则闭合。** 用上面的时间戳、零辅助状态、未知标签、τ＝0、取消和重复包反例，统一每个状态的含义、更新、扣减、衰减和清理。先修设计文字，暂不铺实现。
2. **只清点日志是否够用。** 需要实际候选、事件先后、准入／出队、标签、载荷／线速长度、原始 QP／代际、完成／取消。没有出队事件就不能声称重建 U；新尺寸输入没有对应包事件就不能用旧 trace 冒充其基线。
3. **再做有边界的离线筛查。** 按有两候选、类别合格、近 tie 等条件报告分母，保留逐决定记录。只评价旧策略状态上的信号与动作机会，不称动态收益或最优上界。严格相同与低比例不同分开解释。
4. **C3 单独测时序。** 用端口和 QP 实际时间区间回答回收，而非聚合 B/C。按类、目的和借用事件分层，不把挑出的有利子群当独立确认集。
5. **最后才由主对话决定受控接入。** 只有纸面规则一致、可见性充分且有明确可证伪问题，才考虑新固定源码、正确性和新的配对网络证据。C1 可先保留信息检验，C2 可作计时／资格对照，C3 可先作回收测量；MACA 等只列候选假设，不按评审的 venue 预测排序立项。

建议主对话暂缓新增效果矩阵与候选扩展，先完成上述文档和证据门。这不取消原本必须的身份、完成回调、共享协议、两代正确性、独立 V0、匹配消融、双侧效果与成本任务；若更改范围，应另作明确决定及承接。主入口的 source guard 由主对话持有，本轮未修改或释放。
