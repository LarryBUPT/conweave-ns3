## 4. 已形成的设计决策

不扩宽或改写基线 FlowIDNUMTag 的类体。受控编码器和登记限制 ID 为 0～65535；实际 G1 和全部生产构包入口仍须在编码前保证身份域及唯一性。已截断的外来 tag 无法由 Peek 恢复原整数，C2 的真实网络接线义务没有完成。

异常不生成虚假 token 闭合。包装保存原失败并正常返回，让旧模拟器完成事件引用释放；它不证明所有对象已回收。部分异常夹具是在准确变更边界受控抛出，不称为实际内存耗尽或调度器插入失败；动画失败使用真实 trace 回调。
