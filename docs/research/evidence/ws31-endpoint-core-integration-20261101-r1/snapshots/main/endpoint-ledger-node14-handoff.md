## 1. 本对话目标

## 2. 已确认的项目事实

唯一副在 cursor 95 完成本地只读审查，未编译或访问远端。主独核 11 个固定源对象、报告／JSON／QA 及两份 WIP 前后字节，见[主验收](evidence/endpoint-ledger-local-review-main-acceptance-r1.json)。原 WIP 保存于 `evidence/endpoint-ledger-wip-r1-preserved/`，旧报告与计划保留。

生产 TX／RX packed key 可让不同完整 tuple 碰撞；C1／C3 的四元组又不含 pg。队列组 `Clear()` 仅清向量，finished 位不会随之重置。调度器先查该位，因此直接复用旧索引存在跳过新 QP 的路径。此为源码发现，尚无本轮网络失败。

ACK／NACK 只在输入包有身份标签时复制，纠正了旧设计的“无条件复制”描述。现有 QP 完成回调仍先于 TX 映射删除；必须分别观察完成、映射退出及 Receive 返回。

## 4. 已形成的设计决策

真实夹具采用保留旧已完成 QP、追加新 QP，保持现有键和调度器。禁止直接 Clear 后重用索引；实际旧完成位分支仍须由后继 NS-3 夹具覆盖。

当前是完成型、无背景、下一代需求在旧清理后到达的最小夹具。它不提供取消终态，也不把手工字段覆盖标记当作真实测量。held copy 的明确丢弃只证明本地持有凭据已闭合，不证明原生接收端拒绝了旧包。
