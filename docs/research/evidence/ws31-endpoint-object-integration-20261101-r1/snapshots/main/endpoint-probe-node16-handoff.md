## 4. 已形成的设计决策

setup 的 GetObject 查找放在纯度区间之前，Read 不补查实际 driver。保守 pending 与物理队列分开，不调用有副作用的 GetBytesLeft／IsFinished／RDMA GetNBytes 或调度器。

mask 仍为 127；即使对象被手工设为静默，也不能成为完整 ALL 证书。实际对象纯度、自然传输完成和网络排空分别验证。保留旧 QP、追加新槽位的对象测试不替代第二代实际发送。
