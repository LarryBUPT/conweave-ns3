## 3. 真实 CC、SACK 和正确边界

state profile 的每轮请求为 256 KiB，间隔 10 ms。每轮从主机 1、2 各发 4 个 2 MiB 背景 QP 到主机 3，探针晚 20 μs 到达。两侧背景在真实 40 Gbps 下游出口竞争；40 Gbps 的 ECN 阈值仍使用原夹具的 kmin=100、kmax=400、pmax=0.2，没有为本轮改变阈值。源侧两条等跳路径的传播时延为 10 μs/1 μs，其余原链路不变。该时延差为 U12 的实际换口提供乱序条件，未直接注入乱序包、CNP 或 SACK。

被动状态快照记录发送/接收 QP 地址、serial、累计序号/ACK、SACK 字节、recovery 标志及边界、rate、target rate、alpha、first-CNP 状态和计时器 UID/运行状态。`sack_insert` 位于原 SACK 插入之后，`recovery_enter` 位于原恢复分支之后，`rate_decrease` 位于原降速之后。观测历史计数仅在这些真实分支累计，协议不会读取这些计数。

接收侧单列 `ecn_bits` 和原 `cnp_check`。原实现也会为乱序生成带 CNP 的反馈，因此仅见 CNP 不足以证明物理拥塞。本契约要求 state 持久格观测到真实接收 ECN、真实 CNP，以及后续 rate-decrease 分支的非初始速率。U12 持久格还要求真实接收 gap、非空接收/发送 SACK 和恢复进入；缺失任何条件都不能宣称该覆盖完成。首 CNP 的默认 rate fraction 为 1，故验收没有错误地要求第一条 CNP 回调立刻降速。

完成上一轮后，非空 SACK 应当清空。设已放行上限为 B，未放行后续字节，则 SACK 块均属于 B 以内；累计 ACK 到 B 后，原 `discardUpTo(snd_una)` 清除这些块。恢复边界不超过已发送上限 B，原恢复退出条件也应成立。因此下一轮的正确验收是 SACK 空、恢复已退出，而不是强求带着未完成状态进入下一轮。

跨轮保留由同一对象、累计序号/ACK、真实事件历史和非初始 CC 状态证明。Release 的 before/after 快照要求除放行上限外的所有记录字段相同，包括计时器 UID。空闲期间 CC 计时器可以合法更新 alpha/rate，故不要求“前轮完成值等于下轮放行前值”。源代码继续以先前累计 ACK 为放行门槛，没有为了测试而提前释放下一轮。

本设计是完成请求后复用一个模拟 QP。它没有实现允许前轮未完成便追加 WQE 的应用接口，也不把正确清空 SACK 视为重建了 QP。[本地 raw 验收器](../../scripts/verify_ws30_v14_raw.py)已实现这些检查，但尚未读取任何新格结果。

## 4. W5 的实现与观测不干扰契约

[确定性生成器](../../scripts/make_ws30_v14_inputs.py)已生成并冻结 W5 的四份完整 trace 和一份持续诊断前缀。每份完整输入为 16,384 条 8 KiB 消息、8 轮和 32 条 64 MiB 持续背景，共 16,416 条、2,281,701,376 B。两时序只相差前台晚 20 μs；同需求的身份与总字节已核对相同。需求 seed 为 20,263,101/20,263,102，共同模拟 seed 为 1，公共拓扑、传输和原生计时器沿用 [W5 r1 设计](ws30-w5-baseline-comparability-and-pilot-r1.md)。

ConWeave observer 只记录实际 tx INIT/TAIL/phase/path 状态变化、接收标记和缓冲、reply 到达/处理、NOTIFY 接收及 VOQ flush。匹配到请求的 reply 才输出实测 RTT；无法匹配时为 −1。接收数据事件的 age 为包源时间戳到接收的年龄，flush 的 age 为从首个入 VOQ 包到释放的等待。不同事件的 age 按此语义解释。反馈包的原生生成、计时、随机调用和路径状态均未改动。

observer 只写自己的 map、日志及明确的观测计数。它不调用 `GetBytesLeft/IsFinished`，因为这两个函数在本模拟器中可能消费 SACK。W5 事件日志限 64 MiB；生命周期状态日志也限 64 MiB，完整路由沿用原一百万行上限。溢出即失败停止后续新格。

[静态审计 r4](evidence/ws30-v14-static-audit-r4.json)确认移除被动 hook 后，ConWeave 源文件与固定原实现仅有空白差异；历史 DRILL、DoLbWs30、DoLbClassReserve 函数体保持一致。新 observer 无 RNG、事件调度、发包或协议 helper 的有副作用调用。生成器重复运行字节一致，远端 worker 通过 Python 3.5 语法解析。当前 PATH 未找到原生 C++ 编译器，本轮没有声称编译成功。

动态不干扰门槛仍待执行：18 格旧控制逐 ID 匹配既有 FCT/完整路径；6 格生命周期关闭观测与对应完整观测 FCT 一致；4 格 ConWeave 资格的两对 FCT 一致。静态等价检查不能代替这些回归。Gemma 等外部方法没有新增简化实现。
