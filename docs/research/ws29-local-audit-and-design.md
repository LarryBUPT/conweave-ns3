## 源码审计与实现缺口

`switch-node.cc::GetOutDev` 只有 mode 20 调用源身份观测与心跳激活。ClassReserve 的 mode 21/25/26/27 直接调用 `DoLbClassReserve`。scratch 也把 WS-21 identity、feedback、heartbeat 限于 mode 20。因此首先需扩展参数链和观测入口，再验证关闭时不改变 ClassReserve。

接收端用 `(sourceToR, ingressPort)` 映射首跳候选。该映射依赖拓扑路径不歧义；多路径与断链重算后都须重核映射，失败时拒用反馈。身份正确性优先于非零 adopted。STATE 的序号表及接收缓存目前没有会话 epoch；会话重启必须同时审查 STATE 旧报告，不能只修心跳。

ClassReserve 对 QP 缓存出口。链路失效后简单更新 `m_rtTable` 不会自动清除旧 QP 缓存。恢复验收必须覆盖已存在 QP 的旧出口失效、重传和完成，而新 QP 选到可用端口只覆盖部分情况。设备 `TakeDown` 清空队列；恢复时须核验 MMU、类别队列、PFC 暂停和发送事件一致。

现有 STATE 为目的 ToR 所见 CE 包数/样本数，包含全路径拥塞信号。它不是某一下游出口的真实队列长度。共同目的最终出口可能让候选指标相近；必须记录同目的双候选样本的差异，不能通过注入合成分数制造效果证据。

## 候选 v1 与增量比较草案

v1 保留 ClassReserve 的两个候选、候选盐、类别本地评分和 QP 固定出口。仅在源 ToR 的新 QP 决策读取真实 STATE；中间交换机继续原规则。只有两个候选都有同目的、当前会话、非零样本、新鲜报告和有效邻接状态时，才比较 CE 比例。比例用整数交叉乘法比较，避免浮点差异；不同则优先低 CE 候选，相同则用原 ClassReserve 评分。其余情况退回原 ClassReserve，并剔除物理 down 端口。

拟议技术参考值为 STATE 10 μs、心跳 200 μs，决策样本年龄上限 20 μs。它们来源于旧技术试验的可行参考，尚非最优配置、业务 SLO 或正式协议。主对话审查后才能冻结。过期报告接收丢弃与缓存决策时失效要分别观测。一次邻接丢失不禁用路径，连续三次超时标 UNKNOWN；link-up 必须经本会话有效确认才恢复反馈资格。

比较臂为 C0（ClassReserve、控制关闭）、C1（同机制、联合控制传输但不采用）、C2（同机制、联合控制并采用）。STATE-only 用于联合通信成本归因。C2−C0 是含通信代价的总增量；C2−C1 是采用行为的条件比较；C1−C0 反映控制报文扰动。不能用 C2−C1 代替总增量。ECMP 仅作补充上下文，不代替第一课题控制。

C1 和 C2 共用同一份控制发送、接收和计费代码，仅“新 QP 是否消费状态”开关不同。C1 仍更新缓存、发送心跳并记录潜在决策，实际出口保持本地决定。C2 改变路径后，后续样本、活动端口及控制报文时序可能随之改变。因此 C2−C1 是闭环采用的系统差异，不能宣称控制扰动逐包完全相消。逐格报告两臂控制字节、消息数、年龄与队列变化；总增量始终以 C2−C0 判定。若需要严格固定控制负载的因果对照，须另行冻结回放诊断，不能把自然闭环配对写成这种证据。

记录总候选版本最多 3 个、每版最多一次诊断修正。本地实现和未通过的工程试验也登记；不靠改名重置名额。首次冻结且进入远程验收的 v1 占用首个名额。参数、评分或路径粒度改变必须登记为修正或新候选；观测器非扰动修补单列原因和回归，不借其修改评分。失败不取消正确性修复，达到效果停止线则保持效果 NO-GO。

## 最小正确性计划及阶段门槛

先完成头部/状态机单测，再做隔离仿真。所有格冻结源码 SHA、LF 输入哈希、ns-3 seed、唯一实验 ID、故障事件时间与资源收据后才运行。本文件不预填尚未冻结的 SHA 或实验 ID。

1. 新源码关闭格与旧 ClassReserve 在固定 8 流混合输入上比较 FCT；另覆盖 mode 20 原功能。开启身份观测和关闭采用的探针对照须无扰动。
2. 两个单次丢失格；五类异常 ACK 格（旧序号、重复/乱序、错误 peer、错误端口、错误 epoch）；一个会话重启格。注入种类和数量分别验收，不按合计拒收数猜测通过。
3. 真实 down、down/up 两格。分别覆盖新 QP 和既存 QP；路由重算与反馈状态转移必须有独立事件。物理 down 不得发新业务，恢复必须先确认。原始失败流保留并修复。
4. 三个状态正确性格：无样本、决策时过期、双候选真实新鲜且可区分。前两格严格退回原本地决定；第三格至少一次 recorded adoption 改变决定，且选择与样本一致。合成注入只验证状态机，不进入效果估计。
5. 同一固定长尾技术输入的四个成本臂：C0、STATE-only、C1、C2。全类 100% 完成，输入/完成字节、队列入出/丢弃守恒、身份无错；STATE/HELLO/ACK 的实际逐跳字节均可对账。记录活动端口峰值和时长、年龄分布、拒收/过期、adopted/fallback。

每格要求资源原始采样和终态摘要完整，文本日志低于 50 MiB；事件日志 overflow 必须为 0。拟沿 WS-28 的可用内存至少 32 GiB、空闲盘至少 100 GiB、1 分钟负载不超过 20、单进程树 RSS 不超过 32 GiB。并发从资源 pilot 逐级验证；吞吐提升不超过 5% 时保留前一档。运行前确认无人作业及系统健康，遇争用或异常暂停新格。

正确性通过后才开放独立需求筛选。拟从既有分布生成筛选、校准及确认三组互不重叠 seed，具体值先与全部历史 manifest 去重。正式样本数、MoE 改善下限、背景损害上限、0/64/128 档约束和成本/年龄预算均须在校准后、正式运行前冻结。WS-28 的 +3% 不能自动成为反馈增量的通用安全线。

新需求效果必须同时报告 MoE 整批完成时间、背景 P99、单 seed 反例及原始完成率；两种 P95 作为描述性补充。乱序、NACK、超时、重传及接收占用先查当前可用观测，缺失项不填零。未完成流不得从尾部分析静默剔除。
