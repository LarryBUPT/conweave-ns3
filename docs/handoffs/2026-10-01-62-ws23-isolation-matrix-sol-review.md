## 2. 已确认的项目事实

固定仿真 SHA 为 `3db2685a3540895bf49e25302bd00465bc0921e2`。三个合成需求 seed × 背景/混合 × ECMP、`shortq2`、`guardhash` 共 18 个有效 ID，完整索引及 FCT 哈希在[机器摘要](../research/evidence/ws23-isolation-matrix-r3-summary.json)。`20261001-200004-ws23-s2301-mix-shortq2` 因原资源收据有零 RSS 运行样本被拒收；有效 ID 为 `20261001-201000-ws23-s2301-mix-shortq2-r`。旧倒序输入和旧 SHA 格不并入比较。

## 3. 已完成工作

全量运行 `verify_ws23_isolation_pilot.py --revision 3`，逐格核对 SHA、输入/拓扑、配置、1/1 或 4/4 完成、流身份和字节、FCT、损失/超时、队列守恒和资源收据，18/18 通过。三个 seed 的背景单独三模式 FCT 哈希逐 seed 一致。另从每格原始结果重新提取逐流 FCT、路由计数、资源峰值形成[报告](../research/ws23-isolation-matrix-r3-report.md)和机器摘要。收束现场 `remote_experiment.py check` 无活动仿真；SSH 查询未见登录用户或 Waf/仿真进程。

## 4. 已形成的设计决策

遵守预注册双侧门槛，不因背景流在 seed 2303 改善而忽略竞争流损害，也不把前两组与 `shortq2` 相同的结果解释为类别隔离收益。历史无效 ID 和 raw 保留，替换 ID 在机器摘要中显式标识。

## 5. 当前状态

WS-23 原预设的传输恢复正确性、跨类共享出口因果前置、三组需求双侧隔离探索及原始复核均已有对应实验与验收。隔离探索结论为 **未达到正向条件**。这项任务可按上述固定合成验证范围收束；真实业务收益、SLO 和普遍安全性没有证据，不能据此主张。提交前工作树待核对，提交后须核实本地与个人 fork 同名分支 SHA。

## 6. 未解决问题
