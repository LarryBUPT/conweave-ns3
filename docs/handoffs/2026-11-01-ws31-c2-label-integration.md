## 4. Checker 字段修正

主脚本最初将 `CHOICE` 的 tag 当成实际包标签，导致四格提前停止核验。固定源码明确在这些 QueuePin 分配中传入字面值 0，实际包标签由 `ROUTE` 记录。旧脚本与更正后的哈希均保留；主修正字段解释后验收，Integration 另按正确语义核对全部五格。

本次要求 `CHOICE` 为 0，`ROUTE` 与策略标签一致，需求记录仍保留原业务标签。仿真源码、raw、计划及验收判据均未因 checker 修正而改变。移除格原先与更正后均要求两类字段为 0，已有收据保持原样。源码定位及历史脚本见本轮快照。
