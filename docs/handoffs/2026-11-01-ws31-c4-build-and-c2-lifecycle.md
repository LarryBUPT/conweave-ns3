## 2. 已确认事实

源码为个人 fork 的 `feature/ws31-candidates@c4b6039beb47e667e6954b56ec770cb6038082fa`。独立 ID `20261101-061544-ws31-ofan-preflight-r1` 的完整日志显示 optimized `-j2` 构建完成 1,463 项任务，用时 354.785 秒；元数据为 `BUILT`。ID 保留原名，名称中的 Ofan 不表示该方法获准进入正式对照。

21 份来源按原字节保存，详见[本地验收收据](../research/evidence/ws31-engineering-checkpoint-20261101-r2/verification.json)。原构建日志的行尾空格保留。远端二进制的哈希来自副回传的远端收据，Integration 没有重新下载二进制或访问远端，不能把来源哈希核对表述为独立验证了远端二进制字节。
