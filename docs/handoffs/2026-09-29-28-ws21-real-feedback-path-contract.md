## 4. 已形成的设计决策

- 反馈须是可序列化、可在 `CustomHeader`/IPv4 转发路径识别的真实报文，并通过 Qbb 链路和普通设备队列；PacketTag、仿真节点共享内存及零延迟 oracle 不算反馈。
- 报告应携带候选身份、采样窗、CE 样本分子/分母、序号和生成时间。目的 ToR 的共享主机出口不作为候选差异信号；无样本、报告丢失、过期、乱序或非法时严格退回既有本地双候选队列决策。
- 报文接收与报文实际被选路逻辑采用分开记录。逻辑负载和真实 packet/逐跳成本分开统计。
- 候选协议号、精确定长及字段宽度、队列优先级和周期参数须在实现时经源码检查和测试冻结；首版 10 µs 周期/新鲜度仅是待校验假设。
