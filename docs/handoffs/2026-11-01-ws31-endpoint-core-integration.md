## 4. 已形成的设计决策

采用完成型、无背景、下一代需求在旧代清理后到达的最小端点契约。保留旧 QP 并追加新 QP，避开 Clear 后索引复用；不改变基线键、调度器或候选算法。新核心的两代测试使用手工快照和运行时异常检查，其源码已固定，但编译／运行结果不在本节点验收范围。

当前对新守卫的核验仅为静态源码与测试锚点。EndpointSnapshot 字段覆盖声明仍由调用方提供，不能当作真实端点、队列、事件或链路测量，不能继承 1f 的默认兼容结果为端点能力证明。
