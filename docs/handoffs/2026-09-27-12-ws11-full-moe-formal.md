# Handoff 12：WS-11 全量同步 MoE 加背景正式现象验证

日期：2026-09-27（中国时间）。来源：由 [项目集成任务](codex://threads/01a0cfac-3176-7590-bf34-c0f176a45118) 委派的 WS-11 任务；本次执行的具体实验 ID 以 [40 格机器摘要](../research/ws11-full-moe-formal-summary.json) 为准，不以对话代替原始证据。

## 3. 已完成工作

- 预注册 [v1–v1.5](../research/ws11-full-moe-prereg-v1.md)：主 192 档、5 组（原始输入加四组行顺序置换）、全类 100% 完成、至少 4/5 正向与 R 中位数 ≥5%、所有 15 个有背景配对的背景 P99 恶化 ≤5%。四组置换仅改变端口/同步事件顺序，不是独立需求样本。资源与恢复修订均在相应后续效果格前落盘，不改主判据。
- 静态核验四份原始文件的 16,384 条同序 MoE、背景嵌套及热点；生成并核验 16 份完整顺序置换 trace。远端审计确认用户空闲、20 物理/40 逻辑核、内存与磁盘充裕；默认单仿真拦截改成互斥锁保护的 1/2/4/8/12 阶梯，独立源码/Waf、`mix/output`、日志和元数据目录保持隔离。资源 pilot `20260926-223300-ws11-pilot-f192@98ca8e6` 全类完成，54 次采样峰值 RSS 4540.21 MiB、仿真 280 s。实际 2 格和 4 格并发验证通过；后期 18 物理核令牌流水线实测最大 1 分钟负载 17.24。
- 40/40 正式格的两类流、trace/拓扑/源码 SHA、FCT、PFC、uplink 与资源收据经 [核验脚本](../../scripts/verify_ws11_formal.py) 重算通过。原始/四顺序种子的 192 档 MoE 交互 5/5 正向，R 中位数 +35.9057%；背景安全 14/15 通过，原始 192 档背景 P99 +6.6527%，所以预注册复合门槛 **no-go**。详见 [正式报告](../research/ws11-full-moe-formal-report.md)。
- 控制器的 SSH 未退出、短连接突发和一次采样器漏启动均记录并恢复。缺收据但仿真成功的诊断 ID `20260926-144756-ws11-02-b192-f` 被排除；新正式 ID `20260927-002500-ws11-02-b192-f-r` 同 SHA/trace/seed 复跑，原始 FCT SHA 相同且有完整资源收据。旧目录和 `stopped` 记录保留，不计作额外正式格。用户要求仿真静默、低频汇总，矩阵未逐格向对话输出日志。

## 4. 已形成的设计决策

**决定：不打开 WS-11 效果门槛。**理由是预注册把背景安全作为复合必要条件；虽 MoE 192 档方向和幅度强，原始组背景 P99 +6.65% 超过 5%，不能事后放宽、剔除原始组或换主档。替代方案“只看 MoE 损害即做 GuardHash 收益”被拒绝，因为会忽略另一类流的预定代价；“用顺序置换当独立需求 seed”也被拒绝，因为它们共享同一流记录多重集。不对 `shortq2`、GuardHash、HarmGate、共享/静态隔离或 APS/FLB-like 强对照作本轮效果声明。

## 5. 当前状态

WS-11 在**预注册全量输入现象验证与资源并发验证**范围内完成，正式现象复合判据 no-go；条件性机制效果阶段未启动。40 个正式结果在本机个人 fork 忽略目录 `results/<实验ID>/` 和远端 `/home/fnl/lzy/results/<实验ID>/`，逐格 SHA 与指标在机器摘要；无在途 ns-3 进程。报告、摘要、核验脚本、Handoff 与状态更新提交后须重新核对本地/`origin` HEAD 与工作树；不能把文档 HEAD 误作仿真 SHA。两份参考仓库保持只读。

## 6. 未解决问题

必须保留：本场景背景安全越线，不能声称 GuardHash 减轻了已验证的双侧安全问题；WS-10 固定总字节 4 档 no-go 也不可重判。可解释：为何全量同步加背景得到强 MoE 交互，而 WS-10 固定总字节主档不成立；为何原始 192 档背景 P99 越线而四组顺序置换未越线；热点目的端、端口分配与背景长尾如何共同作用。NACK/超时缺可靠独立计数器，物理队列占用未启用；这些不可用数据不能推断为零。四组置换不是新需求样本，泛化边界仍需新的独立契约。

## 7. 后续推荐动作

按 WS-12 解释性负结果路线整理 WS-10/11 的不同输入条件、热点与背景代价；如需研究类别感知机制收益，先另立前瞻性场景与双侧安全契约，不能回填 WS-11。若未来新现象门槛通过，再冻结 `shortq2`、GuardHash/HarmGate、共享/静态隔离与等信息强对照矩阵，先核查输入、状态、反馈信息等价和两类流完成率，再谈收益。报告中的 ns-3 结果不等同 SmartNIC/交换芯片/生产部署。
