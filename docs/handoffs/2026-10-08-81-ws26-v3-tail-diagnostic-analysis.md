## 4. 结论与范围

本轮没有发现跨 seed 稳定的尾部拥塞端口、背景源 ToR 改道或方向一致的 CNP 变化。现有证据不支持指定某个 ClassReserve 权重或路由规则作为唯一修正。不得据此自动改候选、重算既有筛选门，也不得将诊断格计入新的 pilot 样本。

这是 NS-3 机制诊断，不证明 v3 的性能、安全性或普遍效果。逐跳 `queued_bytes_max` 是诊断日志中的交换机端口队列观测，不能替代独立的物理 MMU 队列测量。逐流 FCT 差异与逐跳等待的共现也不能单独建立因果关系。
