<a id="tq-001"></a>
## TQ-001：单 seed 是什么？

**通用含义。**`seed`（随机种子）是随机数生成过程的起点。同一生成程序、同一参数和同一 seed 通常可重现同一随机样本。**单 seed** 指本次比较只使用了一份独立的随机样本；在这份样本上跑多个算法，仍只有一个独立样本。样本内有 320 条流，也不等于有 320 个独立 seed。

**本项目口径。**至少要区分两种 seed：①生成流量 trace 的 seed，决定流量样本；②ns-3 仿真的 `RANDOM_SEED`，影响模拟器内的随机行为。原始 `traffic_gen.py` 没有单独设置 Python 随机种子，所以仅记录 `RANDOM_SEED 1` **不能**证明 trace 可重生；配对比较必须保存完全相同的 trace 文件及 SHA-256。WS-09 的三个 320 流技术 pilot 共用同一份 trace、拓扑、源码 SHA 和仿真 seed，因此能做该样本内的配对核对，但独立 trace 样本数仍为 **1**。输入审计见论文项目根目录 `docs/research/10-baseline-fidelity-and-dataflow-audit.md`；[WS-09 机器摘要](research/ws09-validation-summary.json)记录了本轮配对输入。

**容易误解：**“同一个 seed 跑三种算法”是三次仿真运行，不是三次独立重复。想判断趋势是否稳定，需要预先确定多个独立 trace seed，并让每个 seed 下的算法复用该 seed 的同一份 trace。具体重复判据见 [WS-07 实验契约](research/ws07-dual-track-contract.md)。

<a id="tq-002"></a>
## TQ-002：pilot 是什么？

**通用含义。**`pilot` 是先导试验或试运行。在投入完整实验成本前，它检查输入、实现、测量方法和资源预算是否可行，也可暴露明显失败。它可以给出初步数值，但初步数值不自动成为正式结论。

**本项目口径。**WS-09 的 *technical pilot* 用固定的 256 条 MoE 流加 64 条背景流，在相同 trace 和传输条件下跑 `shortq2`、`guardhash`、`guardhashgate`，检查完成率、双候选/门控是否触发、队列计数守恒及运行耗时。它只用了一个独立 trace 样本，也没有完成固定总字节、多 seed 和正式强对照，因此不能据某一格的 FCT 差值宣布 GuardHash 有效。[WS-09 Handoff](handoffs/2026-09-26-10-ws09-guardhash-prototype.md)记录该 pilot 的实验 ID 与限制。

| 层级 | 主要回答的问题 | 本项目中的例子 |
| --- | --- | --- |
| smoke / fidelity check | 程序与既有基线链路能否跑通？ | 四模式最小 fidelity 运行；不用于性能排名。 |
| technical pilot | 新机制、计数和配对输入能否正确运行？资源大致够不够？ | WS-09 单 seed 三模式试运行。 |
| 正式比较 | 效应是否在预先约定的条件和独立样本上稳定，并优于强对照？ | 待 WS-10 现象复核和条件成立后的 WS-11 评估。 |

**容易误解：**`SUCCEEDED` 只表示一次运行通过了运行器的成功条件；它不等于“研究假设成立”。pilot 的正数值或负数值都应保留，但不能拿来事后挑 seed、调阈值或改主指标。

<a id="tq-003"></a>
## TQ-003：ADR 是什么？

**通用含义。**ADR 是 *Architecture Decision Record*，通常译为“架构决策记录”。它用短文档保存一项重要选择的背景、决定、理由、考虑过的替代方案与后果，让后来的人知道为什么这样做。

**本项目口径。**个人 fork 的 `docs/decisions/ADR-###-*.md` 也记录重要研究流程决策，不限于软件架构。[ADR-006](decisions/ADR-006-conditional-guardhash-selection.md)记录 GuardHash 的条件性筛选门槛；[ADR-007](decisions/ADR-007-guardhash-prototype-before-efficacy.md)记录在效果门槛尚未通过时，先允许做可关闭的工程原型，但正式收益判据不变。

**容易误解：**ADR 的 `Accepted` 表示团队采用了这项**决策**，不表示算法效果已被实验验证。效果证据要另看固定源码、实验 ID、原始数据和正式比较。
