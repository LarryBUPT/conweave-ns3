### 新判据如何形成

WS-13 先做有出处的评价口径核对：例如 [DRILL 原论文](https://pbg.cs.illinois.edu/papers/ghorbani17drill.pdf)、[ConWeave 原论文](https://cse.hkust.edu.hk/~kaichen/courses/spring24/comp7215/papers/conweave-sigcomm23.pdf)和[Presto 原论文](https://conferences2.sigcomm.org/sigcomm/2015/pdf/papers/p465.pdf)各自如何报告短流 FCT、长流吞吐/尾部、乱序和负载条件；只借鉴可比的**指标与评价设计**，不照抄某篇在不同传输/拓扑下的改善幅度当本项目的安全线。同时测量本项目 ECMP 与强对照在独立校准 trace 上的自然波动，并查明实际 MoE/背景业务可接受的延迟或吞吐要求。新门槛由这三类证据共同支持，写清数值、单位、比较对象、选择理由和敏感性曲线；若业务 SLO 不可得，报告连续的 MoE—背景权衡并把任何阈值标为研究性判断。校准数据与后续正式验证数据分开，判据在正式运行前冻结。WS-10/11/12 已冻结的 5% 历史判据不变。
