# ADR-010：包流混合负载均衡两课题顺序推进

状态：Accepted。日期：2026-10-02。来源：用户在 WS-23/24 闭环后经多轮 Grill-me 问答作出决定；本决策约束后续研究，不追认历史实验为新机制收益。WS-24 独立分支的 ADR-009 只记录其“仅 ns-3”范围；两决策编号不冲突。

## 背景与目标

研究以开题报告的包流混合场景、问题分析、机制设计、仿真验证流程及目标结论为主线。具体算法原理和实验实现可为形成可信结论调整，不受开题报告中预想的实现细节限制。全部实验仅在远程服务器运行 ns-3；无真实主机、NIC、生产 trace 或硬件验证主张。两个课题以负载均衡为主，乱序控制是次要代价约束。WS-23 的隔离探索 NO-GO 与 WS-24 的合成多 rail 结果是设计约束和旁证，不充当论文两课题的正向结论；WS-10/11/12 的历史 NO-GO 不重判。

## 决策

1. **严格顺序与里程碑。** 第一课题先研究类别感知的包流混合选路，完成机制、独立数据验证和小论文后再投稿；小论文投稿后才启动第二课题的实验，不并行推进两课题。第一课题争取在 **2026-11-02 前完成验证和成稿**，投稿随后进行。第二课题研究有成本、有时效的下游状态反馈选路，需相对第一课题无反馈版证明增量，并事前约束反馈通信成本、过期退回和乱序代价。第二课题结论再支撑毕业论文行稿。
2. **固定现有流量问题。** 第一课题主场景沿 WS-11/12：固定 16,384 条 MoE 流，背景为 0/64/128/192 条的既有分布与追加规则，不增加流量类型或档位。允许从同一分布生成新的独立需求 seed；流量生成方法、种子、trace 内容哈希及共同 ns-3 seed 均须冻结。192 档为主档，64/128 档有事前约束，0 档用于无背景检查。以 WS-11/12 已用的现有主拓扑为首要正式场景；仅在主结果通过且机制解释需要时，用仓库已有拓扑作稳健性复核。
3. **主对照与指标。** 第一课题的正式主对照是原始 ConWeave 仓库固定基线 SHA `a8d2db5f057172ce89730b4f6344c531e34a9302` 中的五个模式：ECMP、DRILL、CONGA、LetFlow、ConWeave。个人 fork 后加的 WS-09/12/18 原型作消融或补充比较。各模式须先在同一混合输入、拓扑、传输条件下通过兼容性与正确性门槛，不能拿不等条件的旧数字直接排名。共同主结果为 **MoE 合成批次完成时间**和**背景流 P99 FCT**；完成率与字节守恒是正确性门槛。背景吞吐、链路利用率与不均衡、上游排队、路径选择、乱序/重传，以及第二课题的反馈年龄和通信成本用于解释与机制验证。缺少的原始观测须先补齐，不能填零。
4. **独立验证与事前判据。** 机制筛选、门槛校准和最终验证使用预先分开的独立需求 seed；同一 seed 下算法臂配对，行顺序置换不算独立需求重复。先以独立 pilot 估计波动和可检测效应，再在正式验证前冻结 MoE 改善下限、背景 P99 最大容许损害、其他档位约束、所需独立样本量、比较口径和停止条件，不用正式结果调整门槛。历史 5% 背景线只是旧研究协议，不自动充当新业务 SLO。
5. **有限迭代。** 两课题各最多三个新的候选机制版本，每版最多一次诊断修正。失败 raw、源码 SHA、输入哈希、实验 ID 和资源收据保留；每次修正用新 SHA 和独立 ID 重验。达到上限仍未过事前双侧门槛，停止该轮、报告 NO-GO 和不能成立的主张，再由用户决定是否另立路线；不无限调参，也不为赶成稿日期放宽判据。

## 方法依据与适用边界

同领域的 [TLB 原论文](https://huhuzizi.github.io/jinbinhu.github.io/papers/TLB-TON-2021-2.pdf)同时评价类别完成时间、长流吞吐、链路利用率与乱序；[DRILL 原论文](https://pbg.cs.illinois.edu/papers/ghorbani17drill.pdf)同时评价均值和尾部 FCT，并以分跳排队解释结果。这里借鉴其“结果指标＋机制解释”结构，再按本项目 MoE 合成批次与背景流定义具体口径；不直接移植其他论文的数值门槛。背景流大小固定时，吞吐与 FCT 信息部分重合，因此先作解释指标。

本 ADR 是研究边界和设计顺序，**不是已冻结的远程实验协议或开始实验的授权**。具体源码 SHA、输入哈希、实验 ID、样本量、资源 pilot 与停止线须按 [远程工作流](../REMOTE_EXPERIMENT_WORKFLOW.md)另行冻结；未过前置门槛不启动正式矩阵。未来论文不得把 ns-3 合成效果写成真实 NIC 或生产效果。
