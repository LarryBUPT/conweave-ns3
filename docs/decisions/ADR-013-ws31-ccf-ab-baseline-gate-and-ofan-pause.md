# ADR-013：WS-31 暂缓 Ofan，新增正式基线采用 CCF A/B 准入条件

状态：Accepted。日期：2026 年 11 月 1 日。来源为 WS-31 主对话 `01a19322-95a5-76e3-a4f5-1f1e9dde81ce` 的直接用户消息，turn `01a1940b-da42-7d93-ac39-164e1a614ffb`。Integration 已核对[原文证据](../research/evidence/ws31-baseline-policy-20261101-r2/user-instruction.json)。

## 决定与理由

用户要求：“Ofan的话暂缓考虑实现吧，优选CCF A/B类会议或期刊文章，非此条件的机制不加入到基线。”据此调整 [ADR-012](ADR-012-ws31-sequential-implementation-and-baselines.md) 中新增对照的自主判断范围：

1. Ofan 暂缓。已有 Ofan/RR 代码、提交和完成收据保留为未准入原型；尚未启动的专门测试按用户范围变更取消，不记为技术失败，不继续专门实现或网络比较。
2. 已在途的 `c4b6039…` 共同构建同时承载 C1/C2/C3，可由唯一副连同 C2 非网络 Stop/Dispose 取消测试完成收尾。共同构建通过只证明对应源码的工程可构建性，不能代替 Ofan 准入或网络性能验证。
3. 新增正式文献机制须有正式发表记录，并核实实际会议或期刊在 CCF 官方目录中的 A/B 类资格。记录出版方版本、CCF 目录版本及具体条目。仅有预印本、计划投稿、作者介绍或未知等级时，不加入正式基线。
4. 达到发表及等级条件后，继续审查相关性、比较必要性、成本、兼容性及实现忠实性；资格符合不自动要求实现。当前没有新增正式方法，也未在本次协调中判定任何具体论文的 CCF 资格。
5. 既有 DRILL、ConWeave、CONGA、ECMP、LetFlow 和 QueuePin 保留。本次为新增对照的门槛，不据此删除既有 ECMP 等比较，也不将研究候选 C1/C2/C3 当作外部发表基线审查。
6. C1 → C2 → C3 的实现授权、匹配消融、正确性、独立双侧效果和资源门不变。WS-29 后置保留；Integration 不接管源码或远端，不恢复旧矩阵。

## 替代安排与后续

此前主决定有条件采用 Ofan，现已被直接用户决定覆盖；旧成本分析、来源核查及工程阶段记录保持原样。尚未指定替代新增基线。Gemma 等若重新进入实现候选，先完成本 ADR 的资格核验，再判断必要性及成本。

主自有执行规则见 `docs/research/ws31/main/baseline-admission-policy-r2.md`。Integration 同步执行清单、项目状态、路线、台账和协调登记，并更新既有 `ws-31` 心跳；保留同一目标和 30 分钟频率，不新增重复自动化。活动中的副不重复派发。
